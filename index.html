客户管理与客资引擎

统一客户档案、线索标签、触达记录与画像沉淀，支持公海池与多渠道导入。

  • 客户池分层：私海 / 公海 / 冷热客户
  • 公海导入：抖音、小红书、视频号 API 接入
  • 客户意向评分模型与分配策略
  • 线索触达 SLA 与跟进提醒

商机管理 + SOP 任务

建立多阶段商机流程，支撑自定义 SOP 任务与评分规则，确保成交可控。

  • 商机阶段：线索 → 量房 → 方案 → 报价 → 合同 → 交付
  • SOP 任务库：可配置任务模板、触发条件
  • 任务评分规则：完成度 / 时效 / 价值贡献
  • 漏斗分析与阶段转化看板

产品与供应链管理

SKU 与多规格组合管理，打通供应商、采购、交付全过程。

  • 产品中心：SKU、系列、规格、材质、颜色维度
  • 多规格管理：BOM 关联、替代料配置
  • 供应商档案与评级、价格体系
  • 采购计划与到货追踪

订单与合同管理

配置器 + 子 BOM 方案生成订单，合同在线签署并管理款项节点。

  • 产品配置器：房型/空间维度配置
  • 子 BOM 关联与报价拆分
  • 订单暂存与批量加入
  • 法大大电子合同对接 + 款项节点管理

财务与费用中心

应收应付、费用报销、采购支出统一闭环，保障资金透明。

  • 应收应付看板与对账
  • 费用中心：报销、采购、运营费用
  • 多维度成本归集：订单/项目/部门
  • 利润与毛利分析

项目交付与售后

项目阶段交付、现场管理、售后工单闭环追踪。

  • 交付计划：进度、里程碑、验收
  • 现场施工协同与材料进场
  • 售后工单：质保、维修、回访
  • 工单 SLA + 服务评分

完整软件结构

支持可部署的前后端分离架构，结合 Spring Boot + Django + Python 服务与 PostgreSQL 数据库。

前端（React + Vite）

  • 应用层：ERP 控制台、移动端应用
  • 组件层：Tailwind UI / 设计系统
  • 数据层：React Query + 状态管理
  • 路由：多角色工作台

后端（Spring Boot + Django + Python）

  • Spring Boot：主业务中台、订单/合同/财务
  • Django：低代码配置、权限与流程引擎
  • Python 服务：AI 评分、报表与集成
  • API 网关：OAuth2 / JWT

数据层

  • PostgreSQL：主库 + 报表库
  • Redis：缓存、队列、锁
  • 对象存储：合同/附件/配置器素材
  • BI：经营看板与预测

部署结构（可落地）

按环境拆分部署，保障前后端与数据可扩展。

配置与流程

Django 管理后台 + 权限与流程引擎

数据与缓存
